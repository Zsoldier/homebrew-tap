# Zsoldier/homebrew-tap

Homebrew tap for my personal tools.

## Formulae

### mic-music-pause
Pause Apple Music while your microphone is in use (Teams/Zoom/FaceTime calls) and
resume when the call ends. See https://github.com/Zsoldier/mic-music-pause.

```sh
brew tap Zsoldier/tap
brew install mic-music-pause
brew services start mic-music-pause
```

Or install the latest development version:

```sh
brew install --HEAD Zsoldier/tap/mic-music-pause
```
